
# MarketDataService Usage Guide

This guide explains how other backend modules can access market data.

## 1. Include the header

```cpp
#include "../market/MarketDataService.h"
```

Adjust the relative include path if your source file is in a different folder.

## 2. Use an existing Market object

```cpp
Market market;
market.addStock(Stock("TCS", "Tata Consultancy Services", 3500.0));

MarketDataService marketData(market);
```

In the complete application, use the shared Market instance rather than creating a separate market for each module.

## 3. Get the current price

```cpp
double price = 0.0;

if (marketData.getCurrentPrice("TCS", price)) {
    // Use price for trade calculations.
} else {
    // The requested stock was not found.
}
```

## 4. Get stock details

```cpp
Stock stock;

if (marketData.getStock("TCS", stock)) {
    // Read stock.getSymbol(), stock.getCompanyName(),
    // and stock.getPrice().
}
```

## 5. Get all stocks

```cpp
std::vector<Stock> stocks = marketData.getAllStocks();
```

## Important

- MarketDataService does not own a separate stock list.
- The Market object must outlive MarketDataService because the service stores a reference to it.
- Check boolean return values before using lookup results.
- Coordinate interface changes with Person 2.

## Get a Stock's Sector

```cpp
std::string sector;

if (marketData.getStockSector("TCS", sector)) {
    // Use the sector, for example "IT".
} else {
    // The stock symbol was not found.
}
```

## Get Price History

```cpp
std::vector<double> history;

if (marketData.getStockPriceHistory("TCS", history)) {
    // Use history to display a price chart.
    // The values are recorded price updates,
    // not necessarily daily historical prices.
} else {
    // The stock symbol was not found.
}
```

Include the required headers in the calling source file:

```cpp
#include <string>
#include <vector>
#include "../market/MarketDataService.h"
```

Adjust the relative include path based on the location of the calling source file.

## Important Notes

- `getStockSector()` and `getStockPriceHistory()` return `false` when the symbol does not exist.
- Price history is currently generated by accepted price updates or supplied during stock construction.
- The module does not currently fetch real-world market data.
- The API server should serialize the stock fields into JSON; this guide does not implement the HTTP server.
